# Сборка и multiloader / multiversion шаблон

Everfall 1.0.0 собирается в восемь отдельных JAR: четыре версии Minecraft × два загрузчика. Общий код не копируется вручную между проектами. Его подготовкой для каждого узла занимается Stonecutter.

## Узлы и зависимости

| Minecraft | Java | Fabric Loader | Fabric API в сборке | NeoForge | YACL | Mod Menu для Fabric |
|---|---|---|---|---|---|---|
| 1.21.1 | 21 | 0.19.5 | 0.116.17+1.21.1 | 21.1.251 | 3.8.2+1.21.1 | 11.0.5 |
| 26.1 | 25 | 0.19.5 | 0.155.3+26.1.2 | 26.1.2.116 | 3.9.7+26.1 | 18.0.2 |
| 26.2 | 25 | 0.19.5 | 0.161.0+26.2 | 26.2.0.88 | 3.9.7+26.2 | 20.0.3 |
| 26.3 | 25 | 0.19.5 | 0.161.0+26.3 | 26.3.0.13-beta | 3.9.7+26.3 | 21.0.0 |

У YACL артефакты имеют суффикс загрузчика. Таблица фиксирует текущие зависимости; источник истины — [stonecutter.properties.toml](../stonecutter.properties.toml). Диапазоны совместимости и список patch-релизов для публикации заданы там отдельно от имён узлов: например, сборка 26.1 разрешает ветку 26.1.x. Это не дополнительные узлы компиляции.

Версия мода — `mod.version = "1.0.0"`. Версия Gradle-артефакта дополнена версией Minecraft; loader входит в имя архива. Не следует использовать JAR другого загрузчика или Minecraft только потому, что номер самого Everfall совпадает.

## Как выбираются исходники

```text
src/main/java             общий код, подготавливаемый Stonecutter
src/main/resources        общие профили, ассеты и шаблоны метаданных
src/fabric/java           только Fabric
src/neoforge/java         только NeoForge
src/mc/legacy/java        GUI/compat/mixins для 1.21.1
src/mc/modern/java        GUI/compat/mixins для всех 26.x
src/<loader>/resources/legacy или modern
                         ресурсы выбранного загрузчика и ветки
versions/<version>-<loader>
                         отдельный Gradle-проект и его build/
```

[settings.gradle.kts](../settings.gradle.kts) объявляет пары `1.21.1-fabric`, `1.21.1-neoforge` и аналогично для 26.1/26.2/26.3. Fabric-парам назначается `build.fabric.gradle.kts`, NeoForge-парам — `build.neoforge.gradle.kts`. Текущий узел для редактирования — `26.3-fabric`, заданный в `stonecutter.gradle.kts`.

Для каждого узла складываются подготовленный общий код, одна точка входа загрузчика и ровно один набор legacy/modern. Эти два набора реализуют одинаковые имена классов: оба одновременно подключать нельзя. Они добавлены как обычные source directories и не проходят ту же обработку условных комментариев, что общий `src/main`.

`stonecutter.gradle.kts` задаёт теги версий/загрузчиков, свойства и замены. В частности, старое имя `ResourceLocation` заменяется на `Identifier` для новых версий. Общий `ActiveScreen` использует условную ветку для доступа к текущему экрану до и после 26.2. Сгенерированные исходники внутри `versions/.../build` вручную не редактируются.

## Различия загрузчиков и Minecraft

Fabric использует `dev.kikugie.loom-back-compat`: он выбирает подходящий Loom для старой remapping-ветки и новых unobfuscated версий. В build-скрипте сохраняется запись `modImplementation`, а совместимость обрабатывает плагин. Для 1.21.1 применяются Mojang mappings и legacy Mixin annotation processor. В разработке подключены отдельные модули Fabric API, YACL и Mod Menu; Mod Menu для готового мода необязателен.

NeoForge использует ModDevGradle и `neoforge-mutex`. Точка входа регистрирует встроенные звуки и клиентскую инициализацию, затем общий runtime; экран настроек подключается через extension point NeoForge. Встроенная задача подготовки Minecraft зависит от генерации Stonecutter.

1.21.1 рисует через `GuiGraphics`, 26.x — через `GuiGraphicsExtractor`. Различаются также способы debug overlay, идентификаторы, звуковые вызовы и fullscreen API. Их скрывают `mc/compat` и выбранные mixin-классы. Мод не использует общий межзагрузочный runtime вроде Architectury.

`processResources` подставляет версию, ограничения Minecraft/загрузчика и уровень Java для mixins. Требование к версии YACL в метаданных обоих загрузчиков — `*`: библиотека обязательна, но её версия не ограничивается. Mod Menu на Fabric также имеет требование `*` и остаётся необязательным. Версии в таблице выше используются для компиляции. Fabric-метаданные исключаются из NeoForge JAR и наоборот. `template.ct` — сохранившееся имя файла class tweaker; в 1.0.0 он содержит только заголовок, фактический доступ к аудиоканалам сделан mixin-accessor'ами.

## Команды

Запускайте команды из корня проекта. На Windows используйте `gradlew.bat`, на других системах — `./gradlew`. Toolchain настроен на Adoptium Java 21/25; Foojay помогает Gradle находить необходимые JDK.

```powershell
.\gradlew.bat :26.3-fabric:build
.\gradlew.bat :26.3-neoforge:build
.\gradlew.bat :26.3-fabric:runClient
.\gradlew.bat :26.3-neoforge:runClient
```

Полная сборка всех поддерживаемых вариантов:

```powershell
.\gradlew.bat :1.21.1-fabric:build :1.21.1-neoforge:build :26.1-fabric:build :26.1-neoforge:build :26.2-fabric:build :26.2-neoforge:build :26.3-fabric:build :26.3-neoforge:build
```

`--offline` пригоден только когда зависимости уже закэшированы. Результаты находятся в `versions/<узел>/build/libs/`. Задача `<узел>:buildAndCollect` собирает и копирует mod JAR и sources JAR в общий `build/libs/1.0.0/`.

Dev-запуски используют общую папку `run/`: настройки, ресурспаки и сохранения разделяются между версиями. Не считайте содержимое `run/` частью распространяемого мода. Регистрация server run в шаблоне не означает наличие серверных функций Everfall.

## Проверка совместимости

Компиляция восьми узлов проверяет API и сборку, но не внешний вид чужих меню. Для визуальной проверки нужны главные и игровые экраны, несколько GUI scale, resize/fullscreen, ручная/автоматическая смена профиля, фон, ввод и звук. После изменения хуков отдельно проверяйте обе GUI-ветки.

Интеграция с FancyMenu не использует его API. Everfall собирает обычные видимые виджеты и факт отрисовки логотипа. Полностью произвольные элементы чужого renderer не становятся препятствиями автоматически. Подробнее — [фон и взаимодействие](BACKGROUND_PARTICLES.md).

Ошибки определения профиля ищите по `[Everfall]` в `logs/latest.log`; ошибки mixin и загрузчика — в том же логе. Счётчик F3 помогает отличить малое количество живых частиц от их нахождения за краями или прозрачности.
