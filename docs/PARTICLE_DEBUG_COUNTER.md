# Счётчик частиц в F3

Счётчик показывает текущее количество живых основных частиц и активных дополнительных эффектов. Он помогает проверять генерацию и сравнивать её с настройкой количества. По умолчанию выключен.

## Minecraft 26.x

В штатных настройках debug overlay найдите категорию **Everfall**, запись `everfall:particle_count`. Она зарегистрирована как обычный `DebugScreenEntry` и изначально имеет состояние `NEVER`.

Разрешите показ в overlay, чтобы видеть строку с F3, либо используйте штатное состояние постоянного показа. Выбор сохраняет Minecraft в своих debug-настройках. В YACL эта настройка не дублируется.

## Minecraft 1.21.1

В общих настройках Everfall включите **Количество частиц в F3** (`showParticleCount`, по умолчанию `false`). Эта версия не имеет такой же системы настраиваемых debug entries, поэтому используется отдельная совместимая реализация.

В мире строка добавляется к обычному F3. В экранах главного меню F3 отдельно переключает строку с привычным debug-фоном и текстом.

## Что означает число

Один светлячок считается одной частицей, хотя рисуется тремя слоями свечения. Основные частицы считаются по активному буферу, а не по числу непрозрачных пикселей на экране. Поэтому прозрачный спрайт или частица, ещё подходящая из-за входного края, может входить в число.

`maxParticles` — общий предел и цель генерации. Текущее число может быть меньше при заполнении, после удаления или сброса; счётчик не является FPS, числом вершин или выделенных объектов. Подробности расчёта — в [описании движка](PARTICLE_ENGINE.md).

Строка скрывается без подходящего открытого экрана, при выключенном моде и в игровых меню, если отключён показ во время игры. Фоновая сцена учитывается. Для подходящей активной сцены допустим ноль; при reload или сбросе старое значение очищается.

После изменения счётчика проверьте выключенное состояние по умолчанию, сохранение выбора, добавление/исчезновение светлячков, выход из GUI, фон и `showInWorld`. На 1.21.1 отдельно проверьте переключение F3 в главном меню.
