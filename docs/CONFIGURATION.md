# Настройки и использование

Everfall устанавливается на клиент. Выберите JAR для своей версии Minecraft и загрузчика, установите соответствующий YACL. На Fabric настройки открываются через Mod Menu; на NeoForge — через экран модов. Серверу Everfall не нужен.

## Основные параметры

Файл настроек — `config/everfall.json5`. В таблице указаны исходные значения класса конфигурации: выбранный профиль может заменить количество, ветер, гравитацию и два переключателя поведения.

| Ключ | Исходное значение | Назначение |
|---|---|---|
| `enabled` | `true` | Включить отображение частиц |
| `masterVolume` | `100` | Общая громкость мода, 0–100% |
| `showInWorld` | `false` | Показывать частицы в экранах, открытых во время игры |
| `backgroundParticles` | `false` | Разместить частицы за содержимым интерфейса |
| `interactionEnabled` | `true` | Приземление, смахивание, захват мышью и их звуки |
| `autoSeason` | `true` | Выбирать сезонный профиль автоматически |
| `profile` | `"autumn"` | ID текущего основного профиля |
| `pixelMode` | `"DISPLAY"` | Координаты движения: системные или игровые пиксели |
| `maxParticles` | `200` | Общий предел и целевое количество частиц всех слоёв |
| `wind` | `-50` | Ветер: отрицательный влево, положительный вправо |
| `gravity` | `40` | Гравитация: вниз при плюсе, вверх при минусе |
| `additionalProfiles` | `["fireflies"]` | Разрешённые дополнительные эффекты |

В GUI количество регулируется от 0 до 1000, ветер — от −300 до 300, гравитация — от −100 до 100. Ноль частиц отключает генерацию. Отдельного параметра плотности нет. Отрицательная гравитация используется, например, профилем огня.

В JSON можно задать количество до 100 000. Загрузка и сохранение ограничивают `maxParticles` диапазоном 0–100 000; движки дополнительно соблюдают этот предел. Это защита от чрезмерного выделения памяти, а не рекомендация для повседневного использования.

## Выбор профиля

Поставка содержит `spring`, `summer`, `autumn`, `winter` и `fire`. Автовыбор использует четыре сезонных ID и блокирует ручной селектор. Чтобы выбрать огонь или профиль ресурспака, выключите автовыбор.

При ручном выборе встроенные параметры профиля сразу отражаются в полях YACL как несохранённые изменения. Включение автовыбора также подставляет параметры обнаруженного сезона, даже если ID уже совпал. После этого параметры можно настроить вручную.

Нажатие Save сохраняет текущие значения; Cancel отбрасывает несохранённые правки. Сохранение не должно повторно подставлять пресет поверх последующих ручных изменений. За пределами экрана настроек новый автоматически выбранный ID применяет свои параметры один раз.

Поля `defaults.backgroundParticles` и `defaults.interactionEnabled` необязательны: отсутствующее поле оставляет текущее значение. Профиль огня явно включает фон и выключает взаимодействие.

## Движение и видимость

`DISPLAY` использует системные пиксели для движения и мыши. `GUI` использует координатную сетку интерфейса, поэтому скорость на экране зависит от GUI scale. Размер спрайтов следует масштабу интерфейса в обоих режимах. Переключение режима пересоздаёт частицы.

`showInWorld` относится к меню поверх открытого мира: инвентарю, паузе, контейнерам и другим экранам. Мод не рисует частицы в самом игровом мире и не заменяет погоду. Отдельного списка разрешённых экранов в 1.0.0 нет.

Фон принудительно выключает взаимодействие и блокирует его переключатель. При выходе из фонового режима взаимодействие нужно включить самостоятельно. Подробнее: [фон и взаимодействие](BACKGROUND_PARTICLES.md).

## Дополнительные эффекты и диагностика

Раздел особенностей содержит независимые переключатели дополнительных профилей. Выбор разрешает эффект, но не отменяет его условия: светлячки работают только весной/летом с 21:00 до 05:00. Основной и дополнительные слои используют один `maxParticles`.

На Minecraft 1.21.1 в общих настройках есть `showParticleCount` — счётчик для F3, по умолчанию выключен. На 26.x он настраивается через штатные debug entries Minecraft. См. [счётчик](PARTICLE_DEBUG_COUNTER.md).

Если пользовательский профиль не появился, проверьте его ID, расположение и сообщения `[Everfall]` в `logs/latest.log`. После перезагрузки ресурсов переоткройте настройки, чтобы обновить список профилей и особенностей.
