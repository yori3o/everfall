Region hints use the bundled public-domain IANA tz database files `zone.tab` and `backward`.
Source: https://data.iana.org/time-zones/tzdb/ (retrieved 2026-10-17).
Original copyright/public-domain notices are retained in each file.
The game makes no network requests. Geographic time zones use their representative location's latitude.
A country spanning both hemispheres supplies no hemisphere vote without a geographic time zone.
These are regional hints, not a determination of the user's actual location or climate.
